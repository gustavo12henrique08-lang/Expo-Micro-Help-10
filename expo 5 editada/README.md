# Micro Help — Site de Microempreendedorismo

Projeto escolar em HTML, CSS e JavaScript, preparado para hospedagem estática no GitHub Pages.

## Página inicial
A entrada do site é `index.html`.

## Estrutura
- `index.html` — tela de login/entrada
- `login.css` — estilos da tela de login
- `index.js` — validação e navegação do login
- `pagina-inicial.html` — página principal
- `pagina-inicial.css` — estilos da página principal
- `caixa.css` / `caixa.js` — blocos interativos
- `exemplo*.html` — páginas de conteúdo
- `img/` — imagens

Não são usados PHP, Python ou banco de dados; o projeto é estático.
